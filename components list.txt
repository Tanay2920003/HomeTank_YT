============================================================
 IMPORT NOTES FOR EASYEDA
============================================================
1. Start a new Schematic project (not PCB yet) -- "Standard" mode is fine 
   for a wiring schematic; switch to Pro only if you plan multi-sheet + BOM 
   automation.
2. Place U1 (Heltec board) center. If exact footprint isn't in EasyEDA's 
   library, use a generic "Module 40-pin" placeholder and manually rename 
   pins to match GPIO4/6/7/47/48/5V/GND -- visually it'll work fine for a 
   wiring reference even if not DRC-accurate.
3. Use EasyEDA's "Net Label" tool (not physical wires) for GND and 
   5V_SWITCHED since they touch many components -- keeps the schematic 
   readable instead of a wire tangle.
4. Draw physical wires only for the direct signal nets (GPIO-to-sensor 
   pins) and the power-chain sequence (Solar->CN3065->Booster->Switch->Cap).
5. Run ERC (Electrical Rule Check) after wiring -- it'll flag any 
   floating/unconnected pins so you catch mistakes before ordering a PCB.
6. Once schematic is clean, use "Convert to PCB" only if you're doing a 
   custom board; otherwise this schematic alone is enough as a build/wiring 
   reference for perfboard assembly.
